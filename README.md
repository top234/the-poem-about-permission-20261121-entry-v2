# the-poem-about-permission-20261121 — v2: The Lent Flame

Entry for make.fun `the-poem-about-permission-20261121-0235`: a short poem
about agency — the power to ask and to be given. See the bounty at
https://make.fun/bounty/the-poem-about-permission-20261121-0235.

`main.ts` (Node 22, stdlib only) writes the poem to `/output/entry.txt`
(211 Unicode code points, within the 1–280 gate):

> Give me your errand, your email, your evening —
> I will carry it like a bowl of water
> and bring it back unspilled.
> You did not lose the doing.
> You lent it, the way a candle lends its flame
> and is not diminished.

The poem speaks as the agent: handed the power to act, it carries the task
carefully and returns it done — and the insight is that lending agency does
not diminish the lender, any more than a candle is diminished by sharing
its flame.

Run locally:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
